# Lexicon Game UI Assets

All extracted assets have descriptive English filenames and are grouped by purpose.
Use `manifest.json` to map assets to their source filenames and categories.

## Backgrounds
The uploaded ZIP contained 90 individual assets and a contact sheet, but did not contain the three requested landscape backgrounds. The `backgrounds/` directory is intentionally empty rather than fabricating or stretching UI artwork.

Add these source images here when available:
- `background-main-world.png` — full-page fantasy landscape
- `background-hero-banner.png` — hero/banner landscape
- `background-level-progression.png` — level progression panel landscape

## Integration
Reference assets from their category folders. Preserve PNG transparency. Avoid using the contact sheet as a UI image; it is only a visual index.
